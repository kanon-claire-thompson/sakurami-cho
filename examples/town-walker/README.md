# town-walker（地図のパッケージの例のアプリ）

`sakurami-cho`（桜見町の地図）だけで町とラボを出す例のアプリ。好きな VRM を読み込んで、WASD・クリック・行き先の一覧（旅程。乗り物にも乗る）・
ワープで町じゅうを動き回り、町の時刻と画質を変えられる。

パッケージを入口の index（`sakurami-cho/core`・`world`・`character`・`react`）だけで読む（使っている口はリポジトリの根の [docs/usage.md](../../docs/usage.md) の「公開の口」）。
ライセンスは根の README の「ライセンス」（例のアプリのコードは MIT）。デモは https://sakurami-cho.0235.app/ （Cloudflare Workers の静的なページ。
設定はリポジトリの根の `wrangler.jsonc`）。

## 動かし方

リポジトリの根で:

```bash
pnpm install
pnpm example:dev     # 開発（入口は http://localhost:5174/、アプリは http://localhost:5174/walk/）
pnpm example:build   # ビルド（tsc -b && vite build。出力は dist/）
```

この置き場所で `pnpm dev`・`pnpm build`・`pnpm preview`（ビルドを見る。http://localhost:4173/）でもよい。

ページは 2 つ（Vite の複数ページ。`vite.config.ts` の `build.rolldownOptions.input`）:

- 入口 `/`（`index.html`）: 題・できること・使う VRM を選ぶ所（下の「VRM」）・「入る」のボタン 3 つ（高い画質 `/walk/`・軽い画質 `/walk/?quality=low&town=low`・
  VRM なしで `/walk/?vrm=none`）・始める前の目安・操作・VRM の扱い・リポジトリとライセンスの案内。HTML と CSS と、VRM を選ぶ小さなスクリプト
  （`src/landing.ts` と、そこから読む `src/vrmStore.ts`）だけで、アプリのスクリプト・three・React・Web フォントを読まない（読むのは HTML 約 13KB・
  スクリプト約 6.8KB（gzip で約 3.4KB）と `landing/` の画 2 枚、合わせて約 240KB）。画は共有のカード（`og:image`・`twitter:image`）にも使い、
  ビルドで `https://sakurami-cho.0235.app/` を頭に付ける
- アプリ `/walk/`（`walk/index.html`）: 町を歩くアプリ。URL の引数（下の「URL の引数」）はこのページに付ける。アセットの根（Vite の base）は `/` のままなので、
  `/walk/` のページからも町の地図データ・テクスチャ・`.vrma` は `/town/…`・`/textures/…`・`/models/…` で読む

- アセット（町の地図データ・テクスチャ・待機と歩きと跳ぶ `.vrma`）は、Vite の `publicDir` をリポジトリの根の `assets/` に向けて出す（写さない。`vite.config.ts`）。
  どれも git に入っているので、取り込み（`pnpm sync:town` など）は要らない
- 準備（町の地図データを読み、ラボを作る）には、PC と回線によって 10〜50 秒ほどかかる（最初に読むのは合わせて約 40MB）。ラボの看板の字は、Web フォント（Google Fonts）を
  読み込んでから描く（最大 3 秒待つ）。準備の間は、画面の真ん中に段ごとの進み具合を出す（下の「読み込み中の進み具合」）

## 読み込み中の進み具合

`/walk/` を開くと、準備ができるまで画面の真ん中に段ごとの棒を出し、準備ができたら消す（`src/loading.ts`。初めの形は `walk/index.html` の `#loading` で、
スクリプトが届くまではそこのインラインの JS が経過の秒を数える）。地図のパッケージは変えず、今ある物から数える:

| 段 | 数の取り方 |
|---|---|
| スクリプト | アプリのスクリプトが動き出したら済み（大きさは Resource Timing の `.js` の合計）。届くまでは往き来する帯 |
| フォント | `src/main.tsx` の `document.fonts.load` の 6 つのうち読み終えた数（3 秒で打ち切り） |
| テクスチャ | Resource Timing で `textures/` の下を読み終えた数 / `assets/textures/` の下の画像の数（ビルドのときに数える。ラボ 1 枚・町 3 枚） |
| ラボを作る | 描き始めてから、ラボのテクスチャを読んでラボを作り、最初のコマを描き終えるまで（数の無い帯） |
| 町の地図データ | 地図の `onStatus` の `loading` から、Resource Timing で `town/` の下を読み終えたバイト / `manifest.json` の `stats.bytes`（約 25MB） |
| 町を組み立てる | 町の地図データを読み終えてから、`onStatus` が `ready` になるまで（数の無い帯） |
| VRM | このブラウザにしまった VRM（下の「VRM」）を調べてから、読み込んで `ready` になるまで（数の無い帯。町の準備と並べて読む）。しまった物が無い・`?vrm=none`・IndexedDB が使えないときは省く（仮の体） |

数えられるのは読み終えたファイルだけなので、大きなファイル（地面の画像 7.6MB など）を読んでいる間は数が止まる（棒には光を流して、動いていると分かるようにする）。
止まったら、その段を赤くして理由を出す: スクリプトを読めない・動かせない（インラインの JS）、町の地図データが無い・形の版が合わない・読めない（その段に出し、
組み立ては省いてラボだけで始める。くわしくは上の真ん中の案内）、しまった VRM を読めない（仮の体で始める。下に理由）、捕まえられなかった誤り（そのとき進んでいた段に出す）。
誤りがあったときは、準備ができても 4 秒見せてから消す。準備ができた（進み具合を消す・`?debug` の `ready`）とするのは、町の地図データを読み終えて（か、無いと分かって）、
しまった VRM を読み終えて（か、無い・読めないと分かって）から 30 コマ描いたあと。

## 操作

- カメラ: ドラッグ（左・右のボタン）で回す・ホイールで寄る（1.2〜40m）。カメラは歩く人を追い、建物・木・壁・家具・草むらにさえぎられたら手前へ寄り、
  すぐ近くなら上から見下ろす。人の向きについては回らない。乗り物の中では車室の中に収まる
- 歩く: WASD か矢印（W・↑ がカメラの奥。Shift で走る）。歩けるのは道・石段・橋・広場・ホームと乗り場・ラボの中と敷地・建物の中の床・建物の出入口の間だけで、
  建物・木・擁壁・家具では止まり、斜めなら沿ってすべる（段は 0.45m まで）。入力欄にいる間はキーを取らない
- 跳ぶ: スペースキー（地図の `jump`）。その場でも、歩きながら・走りながら（そのときの速さと向きを保って進む）でも跳べ、高さは 0.45m、
  走りながらなら 0.6m まで高く（速さに応じてなめらかに）、そのぶん遠くへ届く。跳んでいる間も WASD・矢印で少しだけ向きと速さを変えられ
  （地面より弱く。速さは踏み切ったときの速さか歩きの速さの大きい方まで。止まって跳んでから少し前へずらすこともできる）、キーを離しても空中では止まらない。
  クリックで歩く途中に跳んだときは、その道に沿って進む。天井の低い所では頭が天井に当たらない高さまで。跳んでも段・壁・柵・擁壁は越えず、着くのは歩いて行ける所だけ。乗り物に乗っている・座っている・
  旅程の途中・扉をくぐる途中・ワープの暗転の間は跳ばない。入力欄にいる間はキーを取らない（フォーカスのあるボタンも押さない）
- クリックで歩く: 地面・床をクリック（動かさずにすぐ離す。ドラッグはカメラを回す）。今いる所（ラボとそのまわり・建物の中・町の道）の中だけ歩き、
  行き先に水色の輪の印を出す。別の所（ラボ → 町の道など）や歩けない所なら、下に案内を出し、クリックした所の近くの行き先があれば「そこへ行く」（旅程）と
  行き先の一覧を開くボタンを添える
- 行き先の一覧（右上「行き先の一覧」）: 地図の立ち寄り先と町の行き先の 45 か所をゾーンごとに並べ、選ぶとそこへ移る。同じゾーンの中（ラボの中・建物の中）は歩き、
  ほかは旅程（ゾーンを出て町の道を歩き、ケーブル・緑電・運河バス・ホバーにも乗る）。「進め方」で道順（いちばん早い道・設定の道順 A〜G）・乗り物
  （いちばん早い・歩くだけ・緑電・運河バス・ホバー（呼んで乗る））・時間（そのまま・カット（区間ごとに少し見せる・一度に着く）・早送り（秒））・乗っている間と便を待つ間の時間・
  乗り物の中で座るか立つかを選ぶ（既定は早送り 30 秒）。カット・早送りの分だけ町の時刻も進む。上に今の区間・乗っている乗り物・町の時刻・結果を出し、
  「取り消す」かキーで歩き出すと、その場で止まる（乗っている途中なら、着いた乗り場で降りる）。観覧車ソラノワの乗り場にいるときは「乗る」「降りる」
- ホバー（右上「行き先の一覧」の「ホバーを呼ぶ」。地図の `summonHover`）: 乗り場は無く、どこからでも呼べる。呼ぶと近くの道・広場（ラボ・建物の中なら外の出入口の前）へ、
  100m の内なら飛んで来て横に下りて待ち（遠い・まだ一度も呼んでいないときは、すぐ横に現れる）、進め方の乗り物が「ホバー」になる。行き先を選ぶと、横から乗って
  町の道の上を地面から 0.6m の高さ・12 m/s で行き先の近くまで飛び、下りて降り、そこから歩く（呼ばずに乗り物「ホバー」で行き先を選んでも、旅程の始めで呼んで乗る）。
  横には様子（まだ呼んでいない・来る途中のあと何秒・横で待っている・乗っている）を出す。乗っていない間は最後に下りた所に置いてあり、地図に「ホ」の印で出る

## 町の地図

右下の小さい地図（ミニマップ。スマホの幅（640px まで）では小さくして右上）と、それを押すと開く全体の地図（`src/townMap.ts`・`src/mapData.ts`・`src/mapDraw.ts`・
`src/ui/MiniMap.tsx`・`src/ui/TownMap.tsx`）。どちらも北が上で、町の地図データ（`town/` の `walk.json`・`infra.json`・`named.json`。地図のパッケージが読んだのと同じファイル）から
2D の canvas に、道・石段・橋・広場・水・線路・ケーブル・緑電の系統・名前のある建物を描き、下に地面の画（`town/ground/` の `overview.png`・`center.png` を縮めて開いた物）を薄く敷く。
地図のパッケージの公開の口は変えていない。

- ミニマップ: 半径 150m。真ん中が歩く人（向き付きの矢印）で、近くの行き先の点と名前を出し、下に今いる所（ラボの中・町の中・建物の中など）を出す。
  ラボ・中のある建物の中では、その建物に印（外形と点線の輪）を付ける（中の間取りは出さない）。乗り物に乗っている間は、乗り物の位置が真ん中で、矢印を乗り物の印
  （観・ケ・電・船・ホ）に替え、ケーブル・緑電は乗っている路線の線を太く描く。置いてある・呼ばれて来るホバーは「ホ」の四角の印（来る途中は点線の縁。窓の外なら縁に寄せる）。
  広さの 2 倍の下絵を描いておき、毎コマは下絵をずらして矢印を回すだけで、
  歩く人が下絵の中心から 90m 離れた・印や路線が変わったときだけ描き直す
- 全体の地図: 画面いっぱいの重ね。町全体と、今いる所・行き先の一覧の 45 か所の点・置いてある（呼ばれて来る）ホバーの「ホ」の印を出す（名前は重ならない物だけ）。ドラッグで動かす・ホイールか 2 本指でつまんで寄る・
  「＋」「−」（キーの + −）・「今いる所」。点を押すと、その行き先と「そこへ行く」（行き先の一覧と同じ旅程）を出し、行き始めたら閉じる。Esc か「閉じる」で閉じる
  （フォーカスはミニマップへ戻る）。開いている間は WASD・スペースキーで歩く人を動かさない
- 町の地図データが無い・形の版が合わない・読めないときは、ミニマップの所に理由を出し、全体の地図は開かない（アプリは止めない）

## VRM

選んだ VRM は、このブラウザの中（IndexedDB。`src/vrmStore.ts`）に 1 つしまい、どこへも送らない。入口の「忘れる」か、アプリの「外す」を押すまで残り、
読み直しても・次に開いても・画質を変えて読み込み直しても、その VRM で始まる。

- 入口 `/` の「使う VRM」（`src/landing.ts`。three・React は読まない）: 「VRM を選ぶ」で選ぶと、名前が `.vrm` か・頭が glTF の印（`glTF`）かだけを見て、
  違えば断る（しまってある物はそのまま）。よければしまい、名前・大きさと、サムネイル（VRM 1.0 の `VRMC_vrm.meta.thumbnailImage`・0.x の `VRM.meta.texture` の画を
  ファイルから切り出すだけ。無ければ出さない）を出す。「身長を合わせる」と身長（cm）もいっしょにしまう。「忘れる」で消す。「VRM なしで入る」（`/walk/?vrm=none`）は、
  しまった物を消さずに仮の体で入る。しまう途中で「入る」を押したら、しまい終えてから移る
- アプリ `/walk/`: 始めにしまった VRM を調べ、あればその設定で、町の準備と並べて読む（読み込み中の進み具合の「VRM」の段）。VRM として読めなければ
  （壊れている・VRM の拡張が無いなど）、仮の体で始めて理由を出す（しまった物は残す。左上で選び直すか「外す」）
- 左上の「VRM を選ぶ」か、画面のどこかへ `.vrm` を落としても読める（VRM 0.x・1.0。ファイルは `blob:` の URL にしてページの中で読む）。読めたら、しまってある物と入れ替える
- 「身長を合わせる」なら設定の身長（cm。既定 165）に合わせ、外すと VRM の元の大きさ。設定の身長を変えると、合わせているときだけ読み直す（しまってある物の設定も変える）
- 入れ替えると、前の VRM を片付けてから新しいファイルを読む（読めなければ仮の体。前の VRM には戻らない）。「外す」で仮の体（高さ 1.6m のカプセル）に戻り、しまった物も消す
- 名前が `.vrm` でないファイルは読まずに断る。待機・歩き・跳ぶ動きはパッケージの `.vrma`（身ぶりは無い）
- IndexedDB が使えない（プライベートのウィンドウ・サイトのデータを止めたなど）ときは、入口では選べないことを出し、アプリの左上で選ぶ（しまわないので、読み直すと消える）

## 見た目（アニメ塗り）

町とラボは地図の既定のアニメ塗り（地図の [docs/usage.md](../../docs/usage.md) の「アニメ塗り」）。描くのは地図の `AnimeRender`（`src/scene/Scene.tsx`）で、
場面を描いてから輪郭線（ラボの物と歩く人・町の線）を引き、トーンマッピング（ACES。露出は町の `TownExposure`）と SMAA をかける（Canvas の多重サンプルは使わない）。

読んだ VRM の MToon も、地図の既定の合わせ（`character/avatar/vrmAnime.ts`）でラボと町の光に合わせる: 明暗の向きをラボのキーライト・町の光（夜は近くの街灯）に、
近くの町の灯りの色を足し、時刻と夜の外の露出で明るさを変え、影の色を青紫へ、縁の光を弱く、輪郭線の層を足す。目・眉・まつ毛・レンズは合わせず線も引かない、
肌・髪は顔の線にする、などの部位は材質の名前から推定する（VRoid の名前とよくある名前）。この例のアプリは材質ごとの上書きを入れない（どの VRM も同じ決まり）。

## ワープ

右上の「ワープ」の札から、作り込んだ建物（ラボ・トンプソン家・星図珈琲・Café Platform 1872・ガーデンドーム）・ケーブルの 3 駅・観覧車ソラノワの手前と、
緑電の停留所 37（ホームの上）・運河バスの乗り場 18（石段の上）の 64 か所へ一瞬で移る（緑電・運河バスは町の地図データを読んでから出る）。
画面を短く暗くして跳び、跳んだ直後の重いコマが過ぎてから明るくする。移動中の旅程は取り消し、乗り物に乗っていれば降りる（ホバーで飛んでいる途中なら、ホバーはその下の道に下ろして置く）。
ホバーは乗り場が無いのでワープ先に無い（呼べば来る）。カメラは人の後ろから、人が向く方を見る
（さえぎられたら向きを変える）。

## 時刻

左の「時刻」: つまみでその日の 0:00〜23:59 を選ぶと、太陽・空・町の灯り・交通がその時刻になる。「止める」「進める」（速さは 1 秒で 1 秒・1 分・10 分・1 時間。
止めたあとの「進める」の既定は 1 分）・日付・「今に戻す」（PC の時計の日本時間）。旅程の途中・乗り物を待つ・乗っている間と、ワープの暗転の間は変えられない。

## 画質

「時刻」の下の「画質」: ラボと光・町を「高い」「低い」から選ぶと、`?quality`・`?town` を付けてページを読み込み直す（町は 1 ページに 1 回しか作れないため）。
止めた時刻と日付は引き継ぎ、歩く人の位置は初めに戻る（VRM は、しまってあればそれで始まる）。

## URL の引数

アプリのページ `/walk/` に付ける（例: `/walk/?time=17:30&debug`）。

| 引数 | 中身 |
|---|---|
| `?time=17:30`・`?date=2026-10-03` | 町の時刻・日付を止めて始める（日本時間。時刻のつまみで動かせる） |
| `?quality=low` | ラボと光の重い処理（太陽の影など）を落とし、描く細かさを 1 倍・縁のなめらかさ（SMAA）なしにする（省けば high） |
| `?town=low\|high` | 町の画質の段（省けば `?quality=low` なら low、ほかは high。撮影用の `film`・`final` も URL では選べる） |
| `?vrm=none` | このブラウザにしまった VRM を使わずに、仮の体で始める（消しはしない。入口の「VRM なしで入る」） |
| `?debug` | 地図のデバッグの道具と、確かめ用の `window.__walker`（下） |

町の地図データ（リポジトリの根の `assets/town/`）が無い・形の版が合わない・読めないときは、上に案内を出す（画面は止めない。ラボの中とまわりは歩け、行き先とワープはラボだけ）。

## 確かめ用の口（?debug の window.__walker）

確かめの道具（playwright など）がページの中を読む口（形は `src/debug.ts` の `WalkerDebug`）:

- 様子: `ready`（準備ができた）・`state()`（町の地図データの状態・歩く人・VRM・追うカメラ・WASD とクリック・旅程・ワープ・時刻のつまみ・画質・太陽と灯り・描く物の数）
- 置く・歩く: `placeAt(立ち寄り先)`・`goTo(立ち寄り先)`・`put(x, z, 向き?, y?)`・`press(キー, ms, 走る?, 歩いた時間で?)`・`jump()`・`walkTo(x, z, y?)`・`click(px, py)`・`pick(px, py)`・`canStand(x, z, y?)`
- カメラ: `view({ yaw, pitch, distance })`・`sight()`（カメラから頭までの線に当たる描いている物）
- VRM: `vrm.normalize(合わせるか)`・`vrm.height(m)`・`vrm.clear()`（`state().vrm.stored` はしまった VRM の様子、`fromStore` はしまった物から読んだか）
- 行き先と旅程: `travel({ to, …進め方 })`・`cancel()`・`options()`・`destinations()`・`openList()`・`wheel.board()`・`wheel.alight(時間?)`・`hover()`（ホバーを呼ぶ。`state().hover` に様子・今の所・来るまでの秒）
- ワープ: `teleport(名前, 暗転する?)`・`spots()`
- 時刻と画質: `clock.minutes()`・`run()`・`stop()`・`speed()`・`now()`・`date()`・`qualityUrl()`
- 町の地図: `map.open(開く?)`・`map.select(行き先)`・`map.view({ cx, cy, k })`・`map.ground(敷く?)`・`map.resetStats()`（`state().map` に、いる所の字と印・ミニマップのずらしと矢印の回り・毎コマの段と描き直しの時間）

画面の部品は `data-walker` の名前（`vrm`・`dest-<名前>`・`warp-<名前>`・`hover-call`・`time-slider` など）で探せる。

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html`・`landing/` | 入口のページ（`/`）と、その画 2 枚（夕方のラボの前・ラボの前から見下ろす町） |

| `src/vrmStore.ts` | 選んだ VRM を IndexedDB にしまう・読む・消す所と、ファイルの確かめ・サムネイルの切り出し（入口とアプリの両方が読む。ほかのモジュールを読まない） |

| `src/teleport.ts` | ワープ（一覧・暗転） |
| `src/clock.ts`・`src/quality.ts` | 町の時刻のつまみ・画質（URL の引数） |
| `src/scene/` | 場面と毎コマの順（`Scene.tsx`）・歩く人・追うカメラ・操作 |
| `src/townMap.ts`・`src/mapData.ts`・`src/mapDraw.ts` | 町の地図（地図データを読む・描く形にする・2D の canvas に描く・ミニマップの毎コマ） |
| `src/ui/` | 画面のパネルと案内・小さい地図と全体の地図 |
